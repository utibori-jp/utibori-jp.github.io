# utibori-jp.github.io

A simple, static profile page served at the root of <https://utibori-jp.github.io/>.

Plain HTML/CSS — no build step. Edit `index.html` / `styles.css` and push to `master`;
the `pages.yml` workflow deploys to GitHub Pages.

The technical blog lives separately at <https://utibori-jp.github.io/homelab-blog/>.
